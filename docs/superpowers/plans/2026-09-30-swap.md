# Swap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let h3-studio take a source video, split it into scenes, replace people with characters using the H3 character-swap LoRA via ComfyUI, and assemble one finished video with the original audio.

**Architecture:** A new isolated package `backend/swap/` (pure modules for scenes, prompts, graph, assembly; a runner that drives ComfyUI; a JSON store under `data/swaps/`; a FastAPI `APIRouter`) plus two new frontend pages. Each swap pass is one callable job on the existing single-GPU `JobStore` FIFO via `submit_callable`.

**Tech Stack:** Python 3 (FastAPI, numpy, ffmpeg via `imageio_ffmpeg`, cv2), ComfyUI HTTP API (existing `backend/comfy.py`), React + TypeScript + TanStack Router/Query + zod.

**Spec:** `docs/superpowers/specs/2026-09-30-swap-design.md` (amended at planning time: per-project cast, quality-dependent chunk size, separate router module).

## Review Focus

- A scene of exactly 124 / 125 / 243 / 244 frames chunks correctly (one vs two chunks, near-equal sizes, no frame lost) — pinned in Task 1.
- A cast entry with an empty `outfit`, a person whose cast entry no longer exists, or a scene with no people — prompt builder raises a clear error / plan skips the scene — pinned in Tasks 2 and 6.
- A pass whose previous pass failed or was cancelled must fail with a clear reason, not silently read a stale file — pinned in Task 5.
- ComfyUI returns a black video or no `SaveVideo` output — pass marked failed with the reason and finished passes are kept — pinned in Task 5.
- A source with a different frame rate (25, 29.97, 30) or no audio track — scenes and assembly still line up to the source duration within one frame per scene — pinned in Tasks 1 and 4.

```python
import subprocess
import numpy as np
import imageio_ffmpeg

FPS = 24

def ffmpeg_exe() -> str:
    return imageio_ffmpeg.get_ffmpeg_exe()

def grid_length(n: int) -> int:
    n = max(5, int(n))
    return ((n - 5 + 16) // 17) * 17 + 5

def frames_at_24(n_src: int, fps_src: float) -> int:
    return max(1, round(n_src * FPS / fps_src))

def split_chunks(n: int, max_chunk: int) -> list[tuple[int, int]]:
    k = max(1, -(-n // max_chunk))
    base, rem = divmod(n, k)
    out, start = [], 0
    for i in range(k):
        size = base + (1 if i < rem else 0)
        out.append((start, start + size - 1)); start += size
    return out
```

`detect_cuts`: read the file with `cv2.VideoCapture` for fps/frame count/width/height; decode gray 96-px-wide frames with `ffmpeg -vf scale=96:-2,format=gray -f rawvideo -` (like the hand-made script), compute mean abs diff between consecutive frames with numpy, cuts = indexes `i+1` where diff > threshold; `has_audio` = `"Audio:" in ffmpeg -i stderr`. `build_scenes`: boundaries `[0]+cuts`, ends `cuts-1 + [frames-1]`; `frames_24 = frames_at_24(end-start+1, fps)`; chunks from `split_chunks`, each with `padded_frames = grid_length(size)`. `extract_segment` runs ffmpeg with filter `select='between(n\,{a}\,{b})',setpts=N/({fps}*TB),fps=24,select='between(n\,{c0}\,{c1})',setpts=N/(24*TB)` plus `,tpad=stop={pad_to - len}:stop_mode=clone` when `pad_to` set, `-frames:v {pad_to or len}`, `-an -c:v libx264 -crf 14 -pix_fmt yuv420p`. `count_frames`: `cv2.VideoCapture(...).get(CAP_PROP_FRAME_COUNT)` is unreliable for re-encoded files, so decode with `ffmpeg -f null` and parse the final `frame=` value.

```python
CLEAN_CLAUSE = ("No light rays, no beams, no streaks, no translucent overlays and no colour gradients anywhere in the frame: "
                "the clothes have flat, uniform colour. Keep the overall brightness, contrast and colour grading exactly as in <Video 1>; "
                "do not darken or tint the picture. Do not add any door, cabinet, window or furniture.")
KEEP_CLAUSE = ("Preserve the source video's camera and framing. Match each person's position, scale, pose and movement throughout the clip. "
               "Do not show the reference photo or its background.")

def build_pass_prompt(person, cast, scene_people, background_text):
    entry = cast.get(person["cast_id"])
    if entry is None: raise PromptError(f"cast entry {person['cast_id']!r} not found")
    if not (entry.get("outfit") or "").strip(): raise PromptError(f"{entry.get('name') or 'this character'} has no outfit text")
    parts = [f"Replace only {person['target_description'].strip()} in <Video 1> with the character in <Picture 1>.",
             "Replace that person's entire head, including hair and face, with the head, hair, face and glasses (if any) of the character in <Picture 1>.",
             f"In every shot this character wears exactly the same outfit: {entry['outfit'].strip()}."]
    if (entry.get("body") or "").strip(): parts.append(f"The character is {entry['body'].strip()}.")
    for other in scene_people:
        if other["id"] == person["id"]: continue
        if other["order"] < person["order"]:
            oc = cast.get(other["cast_id"], {})
            who = (oc.get("appearance") or other["target_description"]).strip()
            keeps = f", keeping {oc['outfit'].strip()} and all of their colours unchanged" if (oc.get("outfit") or "").strip() else ""
            parts.append(f"Leave {who} exactly as they are{keeps}.")
        else:
            parts.append(f"Leave {other['target_description'].strip()} exactly as they are.")
    parts.append((background_text or "").strip() or "The background and the room must stay exactly as in <Video 1>.")
    parts += [CLEAN_CLAUSE, KEEP_CLAUSE]
    return " ".join(parts)
```
